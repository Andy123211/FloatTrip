# 前端统一工作区迁移

前端入口为 `http://localhost:8765`，继续由现有 FastAPI 服务提供，未引入第二套后端或独立静态预览。

- 主页保留奶油色、棕色文字与蜂蜜黄按钮。计划/解析模式均可输入；点击输入框不会提前跳转。提交后在工作区创建新对话并发送一次，登录前的输入会保留。
- 旅行工作区统一使用左侧完整 `ChatPage` 与右侧详情。历史对话抽屉、持久化行程卡片、规划确认、流式回复、等待用户回复、重试、停止、压缩、归档和记忆整理均复用旧逻辑。打开或更新行程不会卸载会话。
- 详情保留每日路线、天气、景点与餐饮、地图导航、周边搜索、手动编辑及撤销重做、当天路线优化/回退、贴士更新、住宿备注。全部操作接入原有 `/api` 接口；分享操作实际复制当前账号可访问的行程链接。
- 用户画像统一为弹窗，复用真实画像与记忆接口，可编辑、确认、添加或忘记偏好。旧 `/profile` 地址打开主页上的画像弹窗。
- 移除独立测试页入口、简化版 AI 会话及虚构的历史记录、画像百分比、地点评分与操作成功提示。地图不可用时明确展示降级状态。

## 验证

在项目根目录执行：

```sh
.venv/bin/python -m pytest tests/test_frontend_delivery.py tests/test_runtime_api.py tests/test_auth.py tests/test_runtime_e2e.py -q
node --test tests/chat-state.test.js tests/navigation-state.test.js
node tests/frontend-studio.smoke.cjs
```

前两组分别通过 30 项和 31 项测试。浏览器回归使用真实前端与隔离接口样例，验证主页输入/单次提交、历史会话与行程卡片、关联行程发送、结果回填、画像弹窗与编辑、手动保存、等待回复恢复、失败重试、停止任务，以及手机端详情可见且无横向溢出；未产生浏览器脚本异常。

浏览器截图输出到 `/tmp/studio-home.png`、`/tmp/studio-detail.png`、`/tmp/studio-mobile.png`。浏览器样例不会写入现有用户数据。外部模型实际生成与高德在线服务仍依赖已有环境配置；本轮没有执行真实付费模型生成。页面继续使用项目现有 CDN 运行时依赖。

## 同页分层整理（2026-09-05）

详情默认顶部合并为标题操作区与日期天气导航，桌面样例测得约 153px。大封面与偏好通过“行程概览”展开，路线与地图在桌面端始终并排。地点详情、周边搜索、替换/添加地点和旅行资料共用地图侧抽屉；手机端使用底部面板。地图底部只常驻一行地点摘要。

浏览操作与编辑操作使用同一个顶部位置。编辑草稿支持跨日期、地图预览、撤销/重做；保存失败保留草稿并提供重试，取消或离开含未保存修改的编辑时确认放弃。地点卡片只显示简要提示，闭馆等重要提醒保留在列表中。后端接口与路由保持不变。

浏览器回归新增：140–160px 默认头部、1000/1440px 桌面并排布局、概览及抽屉开合不重建地图、Esc 关闭、资料草稿与保存、跨日期编辑、撤销重做、拒绝放弃时保留会话、地点搜索替换、保存失败重试、贴士失败重试、手机底部面板。检查截图另存于 `/tmp/studio-drawer.png`、`/tmp/studio-editing.png`、`/tmp/studio-mobile-drawer.png`。
